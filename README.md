# Habitly — Local Habit Tracker

A responsive React + JSX habit tracker. All data is saved in this browser's local storage; there is no backend and no account.

## Features
- Add and delete habits with emoji and accent colors
- Daily completion tracking and streaks
- Monthly calendar with completion indicators
- Daily mood check-ins and optional notes
- 14-day consistency chart and insights
- Export/import JSON backups
- Responsive layout for laptop and mobile

## Requirements
- Node.js 20.19+ or 22.12+ recommended
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite, usually `http://localhost:5173`.

## Production build
```bash
npm run build
npm run preview
```

## Data and privacy
Habitly stores data in local storage for the browser and origin where it is used. It does not sync automatically between browsers or devices. Clearing site data or switching browsers can remove access to the saved data, so use **Export backup** regularly. Import a previously exported JSON file to restore it.

## Notes
- The sample habits are starter examples; delete them or use them as a template.
- Habits begin counting from their creation date.
- Mood notes are available after selecting a mood for that day.
